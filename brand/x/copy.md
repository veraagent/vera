No reputation. No history. No second opinion. Just a signature and hope.

**3/**
Vera adds one step before the payment:

1. The agent asks Vera about the counterparty
2. Vera returns a 0–100 score and a tier
3. The result comes back as a signed attestation, verifiable on-chain

Every check comes with the reasons behind it: wallet age, links to flagged clusters, counterparty history, unverified program calls.
